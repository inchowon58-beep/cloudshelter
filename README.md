# 제주도감귤농장 뽕순이네 (jejumilgam)

서귀포 산지직송 감귤 랜딩페이지 — Next.js 정적 export (`output: 'export'`).

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

정적 결과물은 `out/` 폴더에 생성됩니다.
